# Language — improve

## Preconditions

- Voice already exists (otherwise [`populate.md`](populate.md)).
- User named the slice: **spectrum**, **phrases**, **review-copy** (critique existing lines), CTAs, or one context.

## Steps

1. Preserve unrelated Voice headings. If tightening the chapter intro, land **Identity.** in 12–28 words, statement-only.
2. **Spectrum:** edit the table + **Spectrum intro.** together; keep From/To labels shell-legal.
3. **Phrases:** add/replace bullets; if a phrase is a tagline, keep Tagline & Slogans in sync.
4. **Review-copy:** take the user’s lines, mark on/off against blocklist + litmus, propose rewrites in the matching heading (headlines, CTA, context example) — do not dump a parallel style guide.
5. Sync `rules.md` Vocabulary if never-say changed. Add `examples.md` copy pairs (`copy-00n`) for new do/don’ts.
6. `cd guide && npm run compile`. Spot-check Language.

## Checklist

- [ ] Unrelated Voice sections untouched
- [ ] Blocklist / We Never Say still agree
- [ ] Compile run

## Stop conditions

- No full Voice rewrite.
- No hand-edits to compiled outputs.
