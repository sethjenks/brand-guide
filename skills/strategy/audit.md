# Strategy — audit

## Preconditions

- Read [`SKILL.md`](SKILL.md) and current `## Strategy`.
- Markdown wins over stale `brand.json` — recommend compile if they disagree.

## Steps

1. Score compile-required labels (Overview, Promise, Personality, Pillars, Guardrails) as present / thin / missing. Score **What.** word length: short (<12) / ok (12–28) / long (>28).
2. Positioning (`strategy-positioning`): do **Category.** / **Only we.** / related fields render? Is **Only we.** unique, or could any kit claim it? Flag litmus failures.
3. Audience table: empty Wants/Needs; segments that duplicate Positioning **Audience.** without adding thought.
4. Archetype: Primary block complete? **Wheel.** match a catalog id? Commented Secondary/Tertiary is OK — do not treat as missing unless the user asked for a three-ring wheel.
5. Pillars (`strategy-pillars`): rows show Emotional / Functional / Trust when authored.
6. Guardrails vs Voice: cannot-be list should overlap `rules.md` Vocabulary never-say / brand.md We Never Say.
7. Overlay Strategy GUIDE_NAV leaves vs `section-status` (completeness-driven). Report empty/stub by leaf id.
8. Deliver a gap list with suggested op (`improve` scoped to positioning / archetype / guardrails, or full `populate`). Do not invent replacement copy unless asked to fix.

## Rubric

- **What.** is 12–28 words and reads as a brand statement, not a label or Design system pointer
- Overview Problem/Solution could not be swapped onto another product without rewriting
- Pillars are choices, not slogans that all brands share
- Litmus test is stated and used in examples
- Archetype narrative matches **We are** / **We are not**

## Stop conditions

- Report-only by default.
- Do not silently rewrite Sample Brand starter copy during audit.
