# Theme examples

| File | What |
| --- | --- |
| [`DESIGN.default.md`](DESIGN.default.md) | Out-of-box grayscale starter — **reset target** |
| [`DESIGN.revhawk.md`](DESIGN.revhawk.md) | Theme inferred from [rev-hawk.com](https://rev-hawk.com/) |

## Reset

```bash
cd guide && npm run tokens:reset
```

## Apply an example

```bash
cp examples/DESIGN.revhawk.md DESIGN.md
cd guide && npm run tokens
```
